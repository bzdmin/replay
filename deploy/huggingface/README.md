# Replay

**Rehearse a change before you ship it.**

Replay takes a proposed change in plain language, works out what it can reach,
designs behavioural scenarios, executes them against the current and the
proposed code, compares what actually happened, and has a separate agent try to
prove the conclusion wrong.

Built with the Strands Agents SDK on Amazon Bedrock.

Source: <https://github.com/bzdmin/replay>
